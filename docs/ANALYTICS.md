# التحليلات — LIVI

**التنفيذ:** `src/systems/analytics.ts`

---

## 1. المبدأ الحاكم: بلا معرّفات شخصية

جمهورنا قاصرون. التحليلات مصمَّمة بحيث **لا يمكنها تحديد هوية أحد**
حتى لو أراد أحد ذلك:

| القاعدة | التطبيق |
|---|---|
| لا معرّفات إعلانية | لا IDFA · لا GAID · لا بدائل |
| لا بيانات شخصية | لا بريد · لا هاتف · لا تاريخ ميلاد · لا موقع |
| لا نصوص كتبتها اللاعبة | لا يُرسَل أي إدخال حر |
| معرّف الجلسة | عشوائي، يعيش في الذاكرة فقط، لا يُخزَّن |
| إعادة التعيين | تمسح كل شيء فورًا |

`setAnalyticsEnabled(false)` يوقف التجميع ويمسح المخزن المؤقت.

## 2. البنية

```
track(name, props)  →  مخزن مؤقت (500 حدث بحد أقصى)
                          ↓ كل 25 حدثًا، أو عند إخفاء التطبيق
                       flush()  →  Transport (يُوصَّل لاحقًا)
```

- **لا ناقل شبكي مفعّل في V1.** `setTransport()` هي نقطة التوصيل لأي
  مزوّد مستقبلي — ويجب أن يكون مُهيّأً لوضع «موجّه للأطفال».
- فشل الإرسال يعيد الأحداث للمخزن مع احترام السقف (لا نمو بلا حدود).
- كل حدث يحمل `seq` — ترتيبه داخل الجلسة، وهو ما يسمح ببناء المسارات
  (funnels) بلا معرّف مستخدم.

## 4. المسارات (Funnels) الأساسية

**مسار الأونبوردنج**
```
session_start (الأول) → onboarding_complete → chapter_complete(s1_c1)
                      → outfit_changed → session_start (اليوم 2)
```
نقطة التسرّب الحرجة: بين `onboarding_complete` و`chapter_complete`.

**مسار تحويل الإعلان**
```
ad_requested → ad_completed → reward_granted
             → ad_dismissed  (نسبة الترك تقيس جودة الموضع)
             → ad_blocked    (السبب يميّز السقف عن انعدام التوفّر)
```

**مسار الاقتصاد**
```
spend_failed (متكرر) = الأسعار عالية أو المكافآت قليلة
item_purchased بلا outfit_changed = العنصر اشتُري ولم يُرتدَ (إشارة سيئة)
```

## 6. الجاهزية لاختبارات A/B

كل قيم التوازن في `config.ts` وتُقرأ عبر `getConfig()`. إضافة تجربة =
تسليم إعداد مختلف من الخادم وتسمية المجموعة في خصائص الأحداث. لا يحتاج
أي تغيير في كود الميزات.

**أولى التجارب المرشّحة:**
1. زمن تجديد الطاقة (24 دقيقة مقابل 18)
2. سقف الإعلانات (6 مقابل 4)
3. عدد المهام اليومية (3 مقابل 4)
4. مكافأة الفصل الأول (تحفيز مبكر أقوى)
