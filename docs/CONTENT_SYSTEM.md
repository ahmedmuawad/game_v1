# نظام المحتوى — LIVI

---

## 1. المبدأ: المحتوى بيانات، لا كود

كل شيء يواجه اللاعبة — قصص، أزياء، عناصر غرفة، مهام — **بيانات تُحمَّل
وقت التشغيل**، لا كود مبني في الحزمة.

السبب عملي بحت: خطة الاحتفاظ قائمة على نزول محتوى متكرر. لو كل قطعة
جديدة تحتاج بناءً وتحديثًا في المتجر، تصبح وتيرة المحتوى مستحيلة
اقتصاديًا وزمنيًا.

---

## 2. مصادر الحقيقة

| المحتوى | المصدر | المخرَج | تقرؤه |
|---|---|---|---|
| الأزياء والأفاتار | `tools/avatar/wardrobe.py` | `public/avatar/manifest.json` + WebP | `src/content/manifest.ts` |
| طاقم القصة | `tools/avatar/export_cast.py` | `manifest.cast` + WebP | نفس الملف |
| القصص | مكتوبة يدويًا | `public/story/<season>/*.json` | `src/systems/story/` |
| التوازن | `src/systems/config.ts` | افتراضيات + طبقة عن بُعد | `getConfig()` |
| نصوص الواجهة | `src/i18n/strings.ts` | — | `useI18n()` |

**القاعدة الحاسمة:** كتالوج الأزياء يعيش في `wardrobe.py` **مع إعدادات
التصيير**. الصور والبيانات تتولّد من نفس السطر، فيستحيل وجود عنصر بلا
صورة أو صورة بلا عنصر.

## 3. دورة إضافة قطعة أزياء

```python
# tools/avatar/wardrobe.py — سطر واحد
Item('top_tee_mint', 'top', 'tee', (0.62, 0.84, 0.74),
     'تيشيرت نعناعي', 'Mint Tee', rarity='rare', tags=['casual', 'soft']),
```

```bash
npm run export:avatar:full   # يصيّر ويحدّث manifest.json
```

القطعة تظهر في المتجر والخزانة فورًا. **لا كود، لا بناء للتطبيق.**

## 4. دورة إضافة فصل قصة

1. `public/story/s1/s1_c7.json`
2. مدخل في `season.json`
3. `nextChapter: "s1_c7"` في نهاية الفصل السابق

المدقّق يعمل تلقائيًا في التطوير ويكشف المراجع المكسورة والعقد غير
القابلة للوصول قبل أن تصل للاعبة.

---

## 5. الترجمة

**قاعدة معمارية:** صفر نصوص مكتوبة مباشرة في المكوّنات.

- نصوص الواجهة: مفاتيح في `strings.ts` بنوع `LocalizedText`
- نصوص المحتوى: حقول `{ "ar": "...", "en": "..." }` داخل JSON
- المفتاح الناقص يُسجَّل تحذيرًا في التطوير ويرجع للإنجليزية

### التعريب لا الترجمة
النسخة العربية ليست ترجمة حرفية: الأسماء والمدارس والمناسبات والحوار
مكتوبة **أصلًا** بالعربية المصرية. الترجمة الحرفية تُقرأ كـ Google
Translate وتقتل المصداقية فورًا لدى هذا الجمهور.

---

## 6. التحميل عن بُعد (جاهز)

| المحتوى | الجاهزية |
|---|---|
| الفصول | ✅ تغيير `STORY_BASE` وحده |
| الأزياء | ✅ تغيير `BASE` في `manifest.ts` |
| التوازن | ✅ `hydrateConfig()` جاهزة للاستقبال |
| أعلام الميزات | ✅ داخل نفس الإعداد |

في V1 المصدر محلي. الانتقال إلى CDN لا يحتاج تغييرًا في أي كود ميزة.

---

## 7. لوحة تحكم المحتوى (لاحقًا)

الأساس موجود: كل المحتوى JSON بمخطط معروف. اللوحة المستقبلية تحرّر
نفس الملفات وتدفعها للـCDN. لا يحتاج تغييرًا معماريًا — فقط واجهة تحرير
ومراجعة.
