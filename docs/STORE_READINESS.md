# جاهزية النشر على المتجر — LIVI

**آخر تحديث:** 2026-09-02
**حزمة التطبيق:** `com.stop4web.livi`

الوثيقة دي بتفصل بين **اللي خلص** و**اللي لسه واقف** و**اللي محتاج قرار
من صاحب المنتج**. الترتيب حسب اللي بيمنع النشر فعلًا لا حسب المجهود.

---

## 1. مانع نشر — لازم يتحل قبل أي رفع

### 1.1 مفتاح التوقيع
الموجود دلوقتي APK **debug** موقّع بمفتاح تطوير. Play مابيقبلش غير
حزمة موقّعة بمفتاح إصدار.

```bash
keytool -genkey -v -keystore livi-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias livi
```

> **المفتاح ده مايتفقدش أبدًا.** ضياعه معناه إنك مش هتقدر تنشر تحديث
> للتطبيق مدى الحياة — لازم تنشره بحزمة جديدة والمستخدمين يفقدوا كل
> حاجة. خزّنه في مكانين منفصلين على الأقل، وسجّل كلمة السر في مدير كلمات.

بعدها `android/keystore.properties` (متجاهَل في git) و`signingConfigs`
في `android/app/build.gradle`.

### 1.2 سياسة الخصوصية
Play بيطلب رابط سياسة خصوصية **علني** لأي تطبيق، وإلزاميًا لأي تطبيق
موجّه للأطفال. لازم تغطّي: إيه اللي بيتجمع (تحليلات بلا معرّفات حاليًا)،
والإعلانات غير المخصّصة، وإزاي يتعمل حذف بيانات.

### 1.3 قسم «الأمان في البيانات» (Data Safety)
إقرار إلزامي في Play Console. حاليًا التطبيق بيجمع: أحداث تحليلية بلا
معرّف شخصي. **لو الحساب اتفعّل** هيبقى فيه بريد إلكتروني ومعرّف مستخدم
— والإقرار لازم يتحدّث قبل النشر.

### 1.4 برنامج «مصمَّم للعائلات»
جمهور 11–16 يعني التطبيق داخل تحت Families Policy. بيستلزم:
- تصنيف محتوى مناسب
- إعلانات معتمدة للأطفال فقط (الطبقة الحالية `npa: true` — لازم تتأكد
  إن شبكة الإعلان نفسها معتمدة)
- ما فيش جمع بيانات موقع أو معرّفات إعلانية

## 3. لسه واقف

### 3.1 المزامنة — موقوفة على Firebase
المنطق والاختبارات جاهزة في `src/systems/account/`.
**الناقص:** إعدادات تطبيق ويب من Firebase Console.

> **الأثر على النشر:** من غير مزامنة، أي لاعبة بتغيّر موبايلها بتفقد كل
> تقدّمها. مقبول في تجربة، غير مقبول في إصدار.

انظر `DECISIONS.md#D-012` — وفيه تحفّظ مسجَّل على استخدام مشروع Firebase
مشترك مع أربع تطبيقات تانية.

### 3.2 بورتريهات الشخصيات الجديدة
ليلى وريم ونادية بصوت واسم بلا صورة. محتاج بايثون 3.11 + bpy.
مش مانع نشر لكنه ضعف واضح لشخصية محورية زي ليلى.

### 3.3 لقطات المتجر
Play بيطلب لقطتين على الأقل لكل نوع جهاز. الشاشات جاهزة للتصوير.

### 3.4 موسيقى خلفية
المؤثرات مولَّدة برمجيًا وشغّالة. الموسيقى متأجّلة عن قصد — موسيقى وحشة
أسوأ من غير موسيقى، ومحتاجة ترخيص فعلي.

## 4. محتاج قرارك

| السؤال | ليه مهم |
|---|---|
| مشروع Firebase منفصل ولا المشترك؟ | بيانات قاصرين في نفس قاعدة بيانات أربع تطبيقات تانية (D-012) |
| هتفعّل الإعلانات في الإصدار الأول؟ | بيغيّر إقرار Data Safety ومتطلبات Families |
| هتفعّل المشتريات؟ | بيستلزم بوابة والدية قبل أي شاشة دفع |
| السن الأدنى المعلَن؟ | بيحدّد التصنيف ومتطلبات الموافقة الوالدية |

## 5. قبل أول رفع — قائمة تنفيذ

```bash
npm run typecheck && npm test && npm run story:validate   # لازم يعدّوا كلهم
npm run build
npx cap sync android
cd android && ./gradlew bundleRelease                      # AAB لا APK
```

> Play بيطلب **AAB** (`bundleRelease`) لا APK للتطبيقات الجديدة.
> الـAPK للتجربة على جهاز بس.
