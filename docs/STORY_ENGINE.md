# محرك القصص — LIVI

**التنفيذ:** `src/systems/story/` · **المحتوى:** `public/story/`

---

## 1. لماذا محرك data-driven

القصة هي محرك الاحتفاظ الأساسي، ومعناها إن المحتوى لازم ينزل باستمرار.
لو الفصول كانت مكتوبة داخل مكوّنات React، كل فصل جديد يحتاج تحديثًا في
المتجر — يعني أيام انتظار مراجعة، ومستحيل نستجيب لحدث أو مناسبة.

هنا الفصول **ملفات JSON** تُحمَّل وقت التشغيل. تغيير `STORY_BASE` وحده
كافٍ لنقل المصدر إلى CDN.

## 2. أنواع العقد

| النوع | الدور | مرئي؟ |
|---|---|---|
| `say` | حوار شخصية (مع تعبير وجه) | ✅ |
| `narrate` | سرد | ✅ |
| `choice` | نقطة اختيار | ✅ |
| `end` | نهاية الفصل (مكافأة + خطاف) | ✅ |
| `effect` | يطبّق آثارًا ويكمل | ❌ منطق |
| `branch` | يتفرّع حسب شروط | ❌ منطق |
| `stage` | توجيه مسرحي (خلفية، مزاج، من على المسرح) | ❌ منطق |

المحرك يقفز فوق العقد المنطقية تلقائيًا حتى أول عقدة مرئية، ويجمّع
الآثار في الطريق. الواجهة تعرض عقدة واحدة في كل مرة.

## 3. الشروط — بلا `eval`

```json
{ "all": [
    { "trait": "confidence", "op": ">=", "value": 18 },
    { "wearing": "formal" },
    { "not": { "flag": "path_hide" } }
] }
```

الشروط **بنية بيانات مغلقة**، لا نصوص تُقيَّم. السبب أمني لا جمالي:
المحتوى مصمَّم للتحميل عن بُعد، ولو كان التقييم بـ`eval` لبقى كل ملف
فصل قناة تنفيذ كود على جهاز اللاعبة. أي مفتاح غير معروف يرجّع `false`.

### المتغيّرات المتاحة

| الشرط | يستعلم عن |
|---|---|
| `trait` | الثقة · الإبداع · التعاطف · الذكاء |
| `rel` | العلاقة مع شخصية (0–100، الابتدائي 50) |
| `flag` | علم سردي (منطقي/رقم/نص) |
| `has` | امتلاك عنصر |
| `level` | مستوى اللاعبة |
| `chapterDone` | إكمال فصل معيّن |
| **`wearing`** | **وسم أسلوب في الإطلالة الحالية** |
| **`wearingRarity`** | **أعلى ندرة مرتداة** |

### الشرطان الأخيران هما الحاجز التنافسي

`wearing` و `wearingRarity` هما الجسر بين التخصيص والسرد
(`DECISIONS.md#D-003`). الشخصيات تعلّق على ما ترتديه اللاعبة، فالشراء
يكتسب معنى سرديًا بدل أن يكون نشاطًا جانبيًا.

**مواضع التفعيل في الموسم الأول:**
- الفصل 1: نور تلاحظ إطلالتك عند لوحة التسجيل (4 ردود مختلفة)
- الفصل 4: يارا تعلّق قبل البروفة
- الفصل 6: رد فعل الصالة على إطلالتك في العرض

## 4. الآثار

```json
{ "trait": "empathy", "delta": 6 }
{ "rel": "salma", "delta": 10 }
{ "flag": "salma_joined", "value": true }
{ "grant": { "coins": 120, "xp": 45 } }
```

السمات والعلاقات محصورة في 0–100. الأعلام حرّة الشكل.

---

## 5. الاختيارات المقفولة

الخيار غير المتاح **يظهر معطّلًا مع سبب** بدل أن يختفي:

```json
{
  "text": { "ar": "«هنقولها مع بعض.»", "en": "\"We'll say it together.\"" },
  "when": { "all": [
    { "trait": "empathy", "op": ">=", "value": 28 },
    { "rel": "dina", "op": ">=", "value": 62 }
  ]},
  "lockedHint": { "ar": "محتاجة دينا تثق فيكِ أكتر", "en": "Dina needs to trust you more" }
}
```

**القرار مقصود:** الخيار المخفي لا يُعلِّم شيئًا. الخيار المعطَّل يخبر
اللاعبة أن هناك مسارًا آخر ويوضّح ما ينقصها — فيتحوّل الغلق إلى دافع
بدل إحباط. ولو كان الشرط متعلقًا بالإطلالة، الواجهة تضيف إشارة لشاشة
الستايل.

## 6. المدقّق

`validateChapter()` يكشف:
- مراجع لعقد غير موجودة
- عقد غير قابلة للوصول
- فصلًا بلا عقدة نهاية
- اختيارًا بلا خيارات
- الحلقات اللانهائية (سقف 64 قفزة أثناء التشغيل)

يعمل تلقائيًا في وضع التطوير عند تحميل أي فصل.
